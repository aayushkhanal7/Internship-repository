# Vehicle Rental Platform (VRP)

## Project Overview

A Peer-to-Peer Vehicle Rental Platform developed as part of my Django Backend Development Internship at Illionso Technologies.

The platform allows vehicle owners to list their vehicles and enables users to search, book, and rent available vehicles.

## Technology Stack

- Python
- Django
- Django REST Framework
- PostgreSQL
- JWT Authentication
- Bootstrap
- Git & GitHub
- Render.com

## Core Modules

- User Management
- Vehicle Management
- Booking Management
- Email Notifications
- Admin Dashboard
- Contact Form
