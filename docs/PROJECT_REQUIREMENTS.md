# Vehicle Rental Platform (VRP)

## 1. Project Overview

The Vehicle Rental Platform (VRP) is a peer-to-peer vehicle rental system that allows users to list their vehicles and allows other users to search for and rent available vehicles.

The system will provide REST APIs for user authentication, vehicle management, booking management, and other platform functionality.

## 2. Project Objectives

The main objectives of the project are:

- Develop a functional peer-to-peer vehicle rental platform.
- Implement secure user authentication using JWT.
- Allow users to list and manage vehicles.
- Allow users to search and filter available vehicles.
- Implement vehicle booking and availability management.
- Implement booking confirmation and cancellation.
- Send booking-related email notifications.
- Provide administrative management functionality.
- Test APIs using Postman.
- Deploy the application to Render.
- Maintain the project using Git and GitHub.

## 4. Core Modules

### User Module

The user module will provide:

- User registration
- User login
- JWT authentication
- User profile management
- Authentication and authorization

### Vehicle Module

The vehicle module will provide:

- Vehicle creation
- Vehicle listing
- Vehicle details
- Vehicle updating
- Vehicle deletion
- Vehicle type classification
- Vehicle search
- Vehicle filtering
- Vehicle availability management

Supported vehicle categories:

- 2 Wheeler
- 3 Wheeler
- 4 Wheeler

### Booking Module

The booking module will provide:

- Vehicle booking
- Booking confirmation
- Booking cancellation
- Booking status management
- Booking date validation
- Vehicle availability validation
- Prevention of overlapping bookings

### Email Notification Module

The system will provide email notifications for important booking events, including booking confirmation.

### Contact Module

The platform will include a contact/inquiry form allowing users to submit messages.

The contact module will store:

- Name
- Email
- Subject
- Message
- Submission date
- Resolution status

### Admin Module

Administrators will be able to manage:

- Users
- Vehicles
- Bookings
- Contact messages
